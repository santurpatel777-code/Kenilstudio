KENIL DIGITAL STUDIO — WEBSITE PROJECT

PAGES
- index.html       Homepage
- about.html       About the studio
- work.html        Portfolio with working category filters
- services.html    Services page
- contact.html     Contact details and enquiry form

CORE FILES
- style.css        Responsive styling, themes, accessibility and layouts
- script.js        Theme switcher, mobile navigation, reveal effects, portfolio filters and enquiry helper
- kenil_studio_transparent.png  Original studio logo
- assets/images/   Optimized WebP versions of the supplied photography

PREVIEW
1. Extract the ZIP file.
2. Keep the folder structure unchanged.
3. Open index.html in a modern browser.
   For best results, run a local server from this folder (for example: python -m http.server 8000)
   and visit http://localhost:8000.

PUBLISH
Upload the complete folder contents, including assets/images, to your web host's public web directory.
Do not upload only the HTML files.

FUNCTIONALITY
- Responsive desktop, tablet and mobile layouts.
- Dark/light theme switch; safely remembers the choice when browser storage is available.
- Mobile navigation with Escape and outside-click closing.
- Active navigation state on each page.
- Portfolio category filters on work.html.
- Reduced-motion support and keyboard focus styles.
- WhatsApp contact shortcut.
- Contact form prepares an email addressed to kenilpatel2605@gmail.com.

IMPORTANT CONTACT FORM NOTE
The contact form uses a mailto link. It opens the visitor's configured email app and does not send or store enquiries on a server. To receive submissions directly without requiring the visitor's email app, connect a form service or backend before launch.
